# FolioOps

**FolioOps** is an open-source initiative focused on democratizing **professional Web portfolio creation**. Any professional from any industry can clone this repository, open it with their favorite AI Agent (Claude, Antigravity, Cursor, etc.), and build a tailored Web portfolio through a guided conversation.

---

## Base Structure (AI Readiness)

```text
FolioOps/
├── .github/     # Governance, Copilot instructions, custom agents, templates & CI workflows
├── AGENTS.md    # Universal instructions and behavior rules for AI Agents
├── CLAUDE.md    # Automatic entry point for Claude
├── GEMINI.md    # Automatic entry point for Antigravity / Gemini
├── README.md    # Project overview
└── .gitignore   # Git ignore rules
```
